# Care workflows

[PORTALS.md](PORTALS.md) documents current synthetic registration/linking, check-ins, uploads, sputum diary, daily care, plans, clinician review, sharing and follow-up. Patient images are documentation only. Care-plan instructions are clinician-entered; no automated diagnosis, prescribing or treatment is provided. The clinician Patients directory now links fictional registration, optional account provisioning and the selected care record; the older standalone care route remains for compatibility. A doctor can complete a dated follow-up once with a private note; the original review is retained, an audit event is written, and completed items leave the due queue and summary. This is documentation, not clinical prioritization. Other review statuses, queue pagination and complete workflow semantics remain open. See [application audit](COMPLETE_APPLICATION_AUDIT.md).
