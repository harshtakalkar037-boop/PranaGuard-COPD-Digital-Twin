# Care workflows

[PORTALS.md](PORTALS.md) documents current synthetic registration/linking, check-ins, uploads, sputum diary, daily care, plans, clinician review, sharing and follow-up. Patient images are documentation only. Care-plan instructions are clinician-entered; no automated diagnosis, prescribing or treatment is provided. Review statuses and queue behavior are the existing implementation, not the complete proposed workflow model; a canonical unified patient directory and further status/queue work remain open. See [application audit](COMPLETE_APPLICATION_AUDIT.md).
