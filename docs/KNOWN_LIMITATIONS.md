# Known limitations

This is a synthetic research prototype, not a clinically validated medical device. The 72-hour model result is below chance on the documented synthetic evaluation and should not drive diagnosis, triage, prescribing or treatment. Environmental context is city-level, not personal exposure; images are documentation only. Full patient-directory unification, complete workflow state management and global-route scoping remain unfinished. Manual accessibility and independent security review remain open. Hosting configuration, persistent SQLite/private uploads, backups, provider connectivity, account assignments and live end-to-end behavior are unverified. See [release readiness](FINAL_RELEASE_READINESS.md) and [current audit](COMPLETE_APPLICATION_AUDIT.md).
